# 个人版文案词典

本词典用于保持个人造价工作台的用户可见语言一致。底层字段、路由 ID、IndexedDB store 和计算逻辑不随文案调整而改变。

| 原表达 | 个人版表达 | 使用规则 |
| --- | --- | --- |
| 企业定额与指标平台 | 个人造价工作台 | 仅用于标题和品牌说明 |
| 负责人经营指挥台 | 我的造价概览 | 首页主标题 |
| 经营规模 | 项目费用概览 | 首页统计卡标题 |
| 项目经营明细 | 我的项目明细 | 项目列表区域 |
| 企业定额库 | 我的定额库 | 导航、页面标题和导入入口 |
| 项目管理 | 我的项目 | 导航和跳转按钮 |
| 经验萃取 | 复盘笔记 | 导航和页面标题 |
| 归档项目 | 收录案例 | 用户操作和状态 |
| 正式样本 | 可用案例 | 面向普通用户的统计说明 |
| 候选样本 | 待检查记录 | 面向普通用户的统计说明 |
| 数据引擎 | 数据整理与指标 | 设置页分组；高级详情可保留原技术名 |
| 血缘 ID | 来源记录 | 来源和追溯说明 |
| 任务队列 | 处理记录 | 设置页高级详情 |
| 组织级造价判断系统 | 可复用的个人造价参考 | 官网和产品介绍 |
| 团队口径 | 我的常用口径 | 业务说明 |
| 审批痕迹 | 调整依据 | 案例和报价说明 |
| 经营健康度 | 资料完整度 | 首页和状态卡 |

## 文案边界

- 保留行业准确术语：定额、工程量清单、报价版本、指标、报价审查、复盘。
- 不在主界面使用负责人、经营、组织级、团队协同、审批流等企业化表达。
- 技术术语可在高级设置、来源详情和处理记录中出现，但必须紧邻白话解释。
- “收录案例”是用户操作名称；底层仍使用现有 archived 状态，避免数据迁移。
