一个纯前端的造价数据库、指标分析和 AI 报价辅助工具。应用不需要后端，业务数据保存在浏览器 IndexedDB，AI Key 仅保存在本机 `localStorage`。

当前版本：`v4.3`，重点完善负责人仪表盘、报价版本复盘和 AI 经验萃取知识库。

## 快速开始

建议通过本地静态服务运行，避免浏览器拦截 ES Module 或演示数据加载：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。不建议直接双击打开 `index.html`。

## 功能模块

| 模块 | 作用 |
| --- | --- |
| 仪表盘 | 负责人经营总览，展示造价趋势、项目组合、版本快照、风险和经验资产健康 |
| 定额库 | 定额 CRUD、Excel 导入、分类/单位/价格状态筛选 |
| 项目管理 | 新建、编辑、归档项目，并直接进入项目清单 |
| 工程量清单 | 选择定额、填写工程量、批量调价、保存报价版本、报价审查和导出报价单 |
| 指标分析 | 基于数据引擎正式样本统计极值、分位数、中位数和均值 |
| AI 助手 | 本地指令 + 远端模型，用于查造价、推荐定额、检查缺单价 |
| 经验萃取 | 将报价审查、版本调整和项目归档里的判断沉淀为可检索、可复核的经验知识库 |
| 设置 | AI 配置、数据引擎、JSON 备份恢复、演示数据加载和重置 |

## 数据导入与备份

定额 Excel 支持“清单名称 / 项目特征 / 单位 / 综合单价”等列。导入后会展示总行数、成功数、失败数、跳过数和缺单价数。综合单价为空或为 0 的条目会被标记为“缺单价”，生成报价时按 0 计。

工程量清单支持“报价版本管理”。当前清单是工作稿，点击“保存版本”会生成不可变快照；可在“版本管理”中查看历史版本、对比两个版本的增删改和总价变化，也可恢复某个版本覆盖当前清单。

保存报价版本、报价审查和项目归档都可以发起“报价复盘经验萃取”。系统会根据当前项目、清单、版本和质量报告生成追问，用户回答后生成经验卡草稿，确认后才进入知识库。

## 数据自动沉淀

系统内置本地数据引擎，所有数据仍保存在浏览器 IndexedDB，不上传服务器。第一版采用审慎自动策略：

- 导入工程量清单 Excel 后，自动生成候选样本和质量报告。
- 保存报价版本后，自动沉淀为不可变版本样本。
- 项目归档后，自动沉淀为正式指标样本并重算指标。
- 指标分析的“样本池”可查看来源、质量、正式/候选状态，并可将候选提升为正式事实。
- 设置页的“数据引擎”面板可查看采集、标准化、质量检查、沉淀入库、指标重建五个阶段的运行记录。
- 数据引擎会为样本写入血缘 ID、来源数据集、质量分和处理任务，便于后续追溯和排查。

缺单价、总价为 0、工程量为 0、未匹配定额的样本会标记为低可信或需复核。默认指标只使用正式事实，不直接使用临时工作稿。

## AI 经验萃取知识库

经验萃取采用“追问 → 草稿 → 确认入库 → 检索复用”的轻闭环：

- 追问由 AI 优先生成；没有 API Key 时使用本地模板兜底。
- 经验卡包含结论、适用边界、风险提示、证据来源、可信度、有效期和复核状态。
- 知识库以条目列表展示，支持关键词、项目类型、工艺类型、成本分类、状态和有效期筛选。
- AI 助手查询经验时优先检索已确认经验卡，并记录复用次数。
- 经验卡不参与造价指标计算，只作为复盘、报价辅助和管理判断的知识资产。

设置页可导出 JSON 备份，也可导入备份恢复到另一台机器。导入 JSON 会覆盖当前定额、项目、清单、报价版本、指标和 AI 配置，建议先导出当前备份。
